The Silent Lantern - Web (Pygbag) project
==========================================
محتوای پوشه:
  main.py                 بازی (نسخه‌ی سازگار با مرورگر؛ منطق، مراحل، داستان و هنر بدون تغییر)
  fonts/DejaVuSans.ttf    فونت همراه پروژه برای متن فارسی (دیگر به فونت سیستم اندروید وابسته نیست)

ساخت نسخه‌ی وب (روی کامپیوتر یا Termux، با اینترنت):
  pip install pygbag
  pygbag --build silent_lantern
  خروجی: silent_lantern/build/web/  (index.html + .apk + favicon)

اجرا روی گوشی:
  1) محتوای build/web را روی GitHub Pages / Netlify / هر هاست استاتیک بگذارید و لینک را در Chrome اندروید باز کنید.
  2) یا برای تست روی همان دستگاه:  pygbag silent_lantern  و باز کردن  http://localhost:8000
  ** مهم: index.html را مستقیماً با file:// باز نکنید؛ کار نمی‌کند. **
  ** اجرای کاملاً آفلاین ممکن نیست مگر اینکه runtime پایتون Pygbag را خودتان کنار فایل‌ها میزبانی کنید؛ اولین اجرا به اینترنت نیاز دارد. **

تغییرات نسبت به نسخه‌ی اصلی:
  - حلقه‌ی اصلی async شد (await asyncio.sleep(0) در هر فریم)
  - thread حذف شد؛ صداها به‌صورت تدریجی در هر فریم ساخته می‌شوند
  - set_mode در مرورگر 960x540 است (مقیاس‌دهی خودکار همچنان فعال)
  - ذخیره‌سازی علاوه بر فایل، در localStorage مرورگر هم نوشته و خوانده می‌شود
  - فونت فارسی از fonts/ بارگذاری می‌شود
